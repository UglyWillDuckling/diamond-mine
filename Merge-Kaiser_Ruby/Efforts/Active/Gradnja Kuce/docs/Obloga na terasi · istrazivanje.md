
Za terasu bih preporučio **gres porculanske pločice** s izgledom sirovog betona (Concrete / Cement look), ali s naglašenom protukliznom površinom.

Najvažnije je da ne gledaš samo izgled nego deklariranu protukliznost.

## Preporučene karakteristike

| Karakteristika | Preporuka                                                       |
| -------------- | --------------------------------------------------------------- |
| Izgled         | Beton / mikrocement                                             |
| Protukliznost  | R11, poželjno R12                                               |
| Površina       | Strukturirana, hrapava                                          |
| Debljina       | 20 mm za vanjsko polaganje na podloške ili odgovarajuću podlogu |
| Otpornost      | Mraz, voda, UV                                                  |
| Upijanje vode  | Porculanski gres, vrlo nisko                                    |

R11 bih postavio kao minimum za vanjsku terasu izloženu kiši. R12 je zanimljiv ako je prioritet maksimalno prianjanje, ali može biti zahtjevniji za čišćenje.
