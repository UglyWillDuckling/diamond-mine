The lower the possibility the bigger the surprise.
In other words, the more options there are things are more difficult to predict and knowing something out **has more value**.

And, in even more words, knowing something is information and the amount of information is proportional to the number of options there are, to the number of possible messages that one os able to choose from.

This can be generalized to say that the greater the number of states that a system can have(see [[entropy]]), the more information each event  or even one state contains.
We can, maybe,  explain this by saying that the system had to choose **not to be** in any other state except this one

and that this information is contained within the current systems state. Again, the more options **there are** the information **there is** in any particular state 'chosen'.

**Back to communication** 

The same reasoning applies to communication, the sender chooses amongst all the messages he/she can send and that **itself** **is the information**, **not** the data being sent over any particular medium. 
If the number of choices is low less data is transferred and vice versa.
Here we also encounter the famous [[bit]], the smallest unit of information that can exist in only 2 states.

**formula**

$$I(E)=\log{\frac{1}{p(E)}}$$
